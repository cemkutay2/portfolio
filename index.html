About Me

Hey, I'm Cem! A beginner GameDev and an artist who loves creating games and music. Here, you can find some projects that I am working on (or have worked on)! If you want to learn more about my background, keep reading. Otherwise, you can skip past the next section.


I've been obsessed with video games and creating since I was a kid. At first, I started uploading “Let's Play” videos on my first-ever YouTube channel (which is now known as “Liveartz”). Then, I moved on to creating 3D channel intros (I know it's cringe now, but it was THE thing back then) using programs like Cinema4D and After Effects. A few years later, I was done with intros.


In 2019, I started learning how to code using Python and mostly used it to create scripts with PyAutoGUI. I had tinkered with Minecraft plugin configs before but had never actually done any “coding.” After I started university, I learned C and reached an intermediate level. However, I've always felt the need to at least try making video games. Since then, I've been using Unity to bring my game ideas to life.


As for my musical side, in 2018, I came across “Launchpad Cover” videos, which immediately caught my interest. After buying a Launchpad, I experimented with Ableton Live, the DAW the Launchpad was designed for, and made REALLY bad music. Through trial and error over the years and learning some basic music theory, I got pretty decent at making music. I've released one full album, an EP, and a lot of singles since then. Now, with my newfound passion for GameDev, I'm trying to merge these two skills and create video game music as well.
